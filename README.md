# Sistema-de-Compras
Sistema de gestão de pedidos e compras. Permite adicionar produtos com nome, preço e quantidade, editar itens, excluir produtos e finalizar compras marcando todos como comprados. Exibe lista com subtotais, status de cada item (pendente/comprado) e valor total pendente. Estatísticas em tempo real mostram total de itens, comprados, pendentes e valor.
